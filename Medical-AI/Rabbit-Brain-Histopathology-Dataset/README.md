# H&E- and Nissl-Stained Histopathological Rabbit Brain Image Dataset

An open histopathological image dataset for multiclass classification of photothrombotic lesions in rabbit brain tissue.

[![Access Dataset v1.0.0](https://img.shields.io/badge/Access%20Dataset-v1.0.0-0A66C2?style=for-the-badge)](https://doi.org/10.5281/zenodo.21787811)

[View the latest dataset version](https://doi.org/10.5281/zenodo.21787810)

## Overview

| Item | Description |
| --- | --- |
| Images | 4,350 BMP image patches |
| Staining modalities | H&E and Nissl |
| Classes | Photothrombotic lesion, necrotic region, and normal tissue |
| Per modality | 2,175 images (725 per class) |
| Current version | 1.0.0 |

## Dataset Access
